Greenwood Public School — Web Portal & Admin Hub
A modern, serverless school portal and administrative dashboard built for Greenwood Public School. The platform utilizes Google Apps Script as a serverless backend, Google Sheets as a relational datastore, and Google Drive for media storage.

🚀 Key Features
🏛️ Public Portal
Interactive Landing Page: Clean, mobile-first design presenting school values, academics, and contact information.

Dynamic Event Calendar: FullCalendar integration displaying real-time events, schedules, and details synchronized from Google Sheets.

Online Admission Inquiries: prospective parents and students can submit admission applications directly through an integrated form.

Student Status & Result Verification: Quick student ID search module providing immediate fee status, attendance percentages, and academic results.

Photo Gallery: Showcase of campus activities, student achievements, and events.

🛠️ Admin Hub
Dashboard Analytics: Real-time counters showing total student enrollments, upcoming events, published notices, and admission inquiries.

Notice Board Management: Instant publishing and categorization of circulars and administrative alerts.

Event Scheduler: Create and manage school calendar events with built-in time/date sanitization.

Student Roster Management: Add student records, update attendance statistics, and post grade outcomes.

Direct Drive File Uploads: Dual-mode gallery manager supporting both direct external image URLs and base64 device uploads directly into Google Drive with public view permissions.

Dynamic School Branding: Real-time updates to school name and tagline saved persistently across app views.
